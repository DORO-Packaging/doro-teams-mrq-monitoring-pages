# DORO Teams MRQ Monitoring

**Application interne DORO de supervision des publications Microsoft Teams dans les équipes MRQ.**
{: .lead}

## Objet

DORO Teams MRQ Monitoring aide DORO à appliquer la règle documentaire suivante dans les équipes Microsoft Teams dont le nom commence par `MRQ-` :

1. déposer les documents dans l’onglet **Fichiers / Documents** du canal approprié ;
2. partager ensuite dans la publication un lien vers le document classé ;
3. éviter le dépôt direct d’un fichier dans une publication.

## Fonctionnement

L’application est installée uniquement dans les équipes Microsoft Teams explicitement autorisées par DORO. Elle analyse les messages de canal afin d’identifier la présence de pièces jointes et d’appliquer les contrôles prévus par l’organisation.

L’application utilise une autorisation Microsoft Teams limitée à l’équipe dans laquelle elle est installée. Elle n’a pas vocation à surveiller les autres équipes Microsoft Teams du tenant.
